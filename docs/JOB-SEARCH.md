# Job Search Platforms

Saved for the job-search phase (after the learning plan). Main targets: **India** and the **Gulf**.

## Primary (India & Gulf infra / cloud roles)

| Platform | Region | Note |
|---|---|---|
| LinkedIn | Global | Still the main place recruiters search; keep the profile strong regardless of feed quality |
| Naukri | India | Largest Indian job board |
| Naukri Gulf | Gulf | Gulf roles |
| Bayt | Gulf | Large Middle East job board |
| GulfTalent | Gulf | Professional Gulf roles |
| Indeed | Global | Broad coverage |

## Noted from social media (mostly US / remote focus)

| Instead of | Suggested | Use it for | Check before relying on it |
|---|---|---|---|
| LinkedIn | Jobcase | US hourly / community jobs | Low relevance for cloud roles |
| Indeed | Hired | Tech roles | Verify it's still operating |
| Glassdoor | Kununu | Employer reviews | Mainly Germany / Europe |
| Upwork | Worksome | Freelance | Enterprise freelance |
| Fiverr | FreeUp | Freelance | US-focused |
| RemoteOK | Pangian | Remote jobs | Remote community |
| FlexJobs | Remotive | Remote jobs | Good remote tech list |
| Monster | Ladders | Senior / high-salary roles | US-focused |
| ZipRecruiter | Jobspresso | Remote jobs | Curated remote list |
| AngelList Talent | Wellfound | Startups | Same company, renamed |

**Strategy:** primary platforms for the main search; remote boards (Remotive, Jobspresso, Pangian, Wellfound) as extra channels for remote cloud/DevOps roles.
