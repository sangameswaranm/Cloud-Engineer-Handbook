## How each topic is taught

What it is → why it exists → how it works → syntax → examples → production use → hands-on lab → break it → troubleshoot → **interview questions** → admin challenge.
Incidents follow the [senior root cause format](ROOT-CAUSE-GUIDE.md). Official docs and videos for every module are in the [Resources Hub](RESOURCES.md).

!!! note "Public handbook"
    Real incidents are used as training material with every client name, hostname, domain, user ID, IP address and ticket number replaced by neutral placeholders.
