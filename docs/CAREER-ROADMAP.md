# 4-Year Career Roadmap

**Destination (by 2030):** Senior Infrastructure Engineer → **Infrastructure Architect / Solution Architect**.
**Starting point (2026):** ~4 years in OCI and cloud networking, with PAM (WALLIX Bastion) and DR architecture exposure; rebuilding fundamentals.

## How the path works

Titles come from **knowledge** (built through study) **plus responsibility at work** (designing, deciding, leading).

```text
Year 1–1.5  Senior-engineer depth (this learning program)          → perform like a senior engineer
Year 2–3    Design ownership at work + architect certifications     → Senior Infra / Lead Engineer
Year 3–4    End-to-end solution design, leading others              → Infrastructure / Solution Architect
```

By year 3 there will be ~7 years of experience. What makes them count as architect-level is **having designed things**, not only operated them.

**Start now at work:** volunteer to write the design document, draft the DR plan, lead the change, present the solution.

## What a senior infra person / architect must know (T-shaped)

Broad knowledge across all areas, **deep** in 2–3 specialties: **cloud networking, OCI, security/PAM**.

| # | Area | Topics |
|---|---|---|
| 1 | Foundations | Linux, Windows Server, networking (TCP/IP, routing, DNS, LB, firewalls, VPN, SD-WAN awareness), **virtualization (VMware / Hyper-V / KVM)**, storage (SAN/NAS, block/file/object), identity (AD, Entra ID, PAM) |
| 2 | Cloud | OCI and Azure in depth, AWS working level, landing zones, hybrid connectivity, governance, FinOps, migration strategies |
| 3 | Automation | Bash, PowerShell, Python, Terraform, Ansible, CI/CD, GitOps |
| 4 | Platforms | Containers, Kubernetes, databases (architecture level), messaging/middleware awareness |
| 5 | Operations | Monitoring, observability, logging, ITIL (incident/change/problem), patching, capacity planning |
| 6 | Resilience | Backup (Veeam, Commvault), DR, HA patterns, business continuity |
| 7 | Security architecture | Zero trust, segmentation, PAM, secrets/PKI, endpoint security (Defender, Trend Micro), SIEM awareness, ISO 27001, **NCA ECC** (Saudi), SAMA (banking) |
| 8 | Architecture skills | Requirements and NFRs, HLD/LLD, decision records, well-architected frameworks, cost modelling, vendor evaluation, reference architectures |
| 9 | Leadership | Presenting and defending designs, leading incidents and CABs, mentoring, estimation |
| 10 | AI for infrastructure | AI agents for operations, platforms for AI workloads |

## Certifications (fewer, well chosen)

| When | Certification | Why |
|---|---|---|
| Year 1 | AZ-104 Azure Administrator | Azure foundation |
| Year 1 | OCI Architect Associate | Quick win with OCI experience |
| Year 1 | **RHCSA** (optional) | Hands-on proof of Linux admin, right after the Linux sprint |
| Year 1–2 | **OCI Networking Professional** | Matches the cloud-networking specialty |
| Year 1–2 | Terraform Associate | Automation proof |
| Year 2 | **AZ-305 Azure Solutions Architect Expert** | Key architect credential |
| Year 2 | OCI Architect Professional | Architect-level OCI |
| Year 2–3 | CKA | Platform depth |
| Year 2–3 | ITIL 4 Foundation | Expected in many infra roles (Gulf) |
| Year 3 | AWS Solutions Architect Associate → Professional | Multi-cloud expected for solution architects |
| Year 3–4 | TOGAF (optional) | Enterprise architecture direction |
| Optional | AZ-700 (networking), **SC-500** (replaces AZ-500), **AZ-802** (Windows Server, replaces AZ-800/801), **AI-103** (AI agents), Veeam VMCE | Strengthen specialties |
