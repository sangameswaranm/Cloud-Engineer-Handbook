# Cost Control

## Rules
1. Don't create cloud resources just to run basic commands; reuse the lab VM.
2. Prefer Always Free / smallest viable shapes.
3. Before any paid resource: identify cost, set a budget and alert, build, test, destroy, verify cleanup.
4. Stop or terminate lab resources when a lab ends.
5. "Free" is never assumed to mean unlimited.
