# Practice Arenas

External practice platforms, mapped to where they fit in the roadmap. Use them **after** the matching topic, as a fun reinforcement.

!!! warning "Company laptop"
    OverTheWire is a security "wargame". Check your company's policy before connecting to it from a work device; use a personal device if unsure.

| Platform | What it is | Use after | Cost |
|---|---|---|---|
| **OverTheWire: Bandit** | Linux puzzle levels over SSH: each level hides the password for the next | Linux Topics 3–6 (files, find, hidden files, permissions) | Free |
| **SadServers** | Real broken Linux servers in the browser with an automatic "fixed?" check | Linux Topics 9–10+ (processes, services), then Topic 37 | Many free; some Pro |
| **KillerCoda** | Browser labs, including broken Kubernetes clusters to fix | Docker & Kubernetes modules (Month 4) | Free |
| **Oh My Git!** | Card game that visualises Git internals with a real Git terminal | CI/CD module (Git), or any time | Free |

## Suggested order

1. **Now (Topics 1–4 done):** Bandit early levels: they practise exactly what you learned: `ls -la` for hidden files, `find` by size and type, reading files, SSH login.
2. **After Topic 10:** SadServers easy scenarios.
3. **Month 4:** KillerCoda Docker/Kubernetes scenarios.
4. **CI/CD module:** Oh My Git!.

## Log it

After a practice session, tell Claude the platform, the levels cleared and the time spent; it's logged like any other session.
